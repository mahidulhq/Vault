# Vault
The Vault: Game Library Management System is a web-based application designed to help users organize and manage a collection of video games. Users can browse the game library, search for games, add games to their favorites, and write reviews. Administrators can add, update, and delete game information, including titles, genres, platforms, age ratings, release years, descriptions, and cover images. The system uses a frontend for user interaction, a backend for processing requests, and a MySQL database to store and manage all information through CRUD (Create, Read, Update, Delete) operations.
